# Geist fonts

Self-hosted official Vercel fonts, licensed under the included SIL Open Font License.
Source: https://github.com/vercel/geist-font (retrieved 2026-11-22).

- Geist Serif Regular: fonts/GeistSerif/webfonts/GeistSerif-Regular.woff2 (Git blob ea217ac1a1d6e4b49f07c6970a373a4a3314a6a6).
- Geist Sans variable: fonts/Geist/webfonts/Geist[wght].woff2.
- Geist Mono variable: fonts/GeistMono/webfonts/GeistMono[wght].woff2.

Every downloaded file was verified against the Git blob SHA returned by the GitHub contents API. `next/font/local` includes only these assets; no Google Fonts request is needed during build or browsing. Serif uses the Regular variant, not Square/Triangle/Heart.
